# nós. — Criar categoria durante o lançamento

- Em **Movimentos → Novo movimento** ou **Movimentos → Novo fixo**, selecione **+ Criar nova categoria**.
- Informe nome e ícone e clique em **Guardar categoria**. A categoria é salva no Supabase e selecionada sem fechar o movimento.
- A categoria recebe automaticamente o tipo Receita ou Despesa conforme o formulário.
- Transferências não usam categorias.
- **Não é necessário executar SQL novo**: usa a tabela `nos_categories` da Fase 4.
- Publique todos os arquivos na raiz do repositório GitHub; aguarde o deploy na Vercel.
- Teste com os dois logins. O código foi validado estaticamente, não no Supabase em produção.
